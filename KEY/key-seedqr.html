KEY · SeedQR

Enter the twelve rows of a seed plate, by tapping the dots or typing the numbers. The page draws them as a SeedQR, the code a SeedSigner reads to load a key without anyone typing a word.

The plate

0000–2047

The code

Enter the twelve numbers.
Practice keys only. A screen that shows this code has seen the whole key. Never enter a key that holds, or will hold, money.
The page works with no network: nothing is stored and nothing is sent. The code is a Standard SeedQR: the twelve four-digit numbers, counted from 0000, written one after another.
